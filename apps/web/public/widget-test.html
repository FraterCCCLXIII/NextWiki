NextWiki AI Widget Test

This page lives in apps/web/public/widget-test.html and loads the embeddable widget via iframe.

Instructions

  1. Start the web app: pnpm run dev:web
  2. Enable the widget in Admin → AI Settings (ai.widget.enabled)
  3. Ensure guest read permission if using public query-only access
  4. Visit http://localhost:4000/widget-test.html (or the current dev server port)

This test page loads the Intercom-style embed script. It injects a launcher iframe and a messenger iframe on the page.

Widget Preview

You should see the AI launcher button in the bottom-right corner of this page.
