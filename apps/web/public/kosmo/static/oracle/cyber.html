CISA's Known Exploited Vulnerabilities catalogue: every CVE the US government has confirmed is being used in the wild. One JSON document, no key, refreshed continuously.

Why this page exists. Logistics, payments, grid control, food distribution and military command all run on the same internet, and not one model in this lab contains a cyber term — because it is hard to quantify, which is not the same as unimportant. This page quantifies the part that is published, and is explicit about what the published part leaves out. The honest summary is that exploitation is dominated by known, patchable, years-old flaws in a handful of internet-facing products, which makes it less like espionage and more like maintenance.
